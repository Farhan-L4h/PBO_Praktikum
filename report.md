# PERTANYAAN DAN JAWABAN

## 1. Jelaskan perbedaan antara object dengan class!

**Jawaban:**

Class adalah blueprint atau rancangan yang mendefinisikan atribut dan method dari suatu objek.

Object adalah hasil instansiasi dari sebuah class yang dapat digunakan untuk merepresentasikan suatu objek.

---

## 2. Jelaskan alasan gear dan brand dapat menjadi atribut dari object Bike!

**Jawaban:**

Gear dan brand dapat menjadi atribut dari object `Bike` karena keduanya merupakan karakteristik atau data yang dimiliki oleh sebuah sepeda.

---

## 3. Sebutkan salah satu kelebihan utama dari pemrograman berorientasi objek dibandingkan dengan pemrograman prosedural!

**Jawaban:**

Salah satu kelebihan Pemrograman Berorientasi Objek (PBO) adalah program lebih mudah dikembangkan dan dikelola dalam skala besar karena kode dapat dibuat lebih terstruktur dan dapat digunakan kembali.

---

## 4. Apakah diperbolehkan melakukan pendefinisian dua buah atribut dalam satu baris kode seperti `public String nama, alamat;`?

**Jawaban:**

Boleh. Dua atau lebih atribut dengan tipe data yang sama dapat didefinisikan dalam satu baris kode.

Contoh:

```java
public String nama, alamat;
```
